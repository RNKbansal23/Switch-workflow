SETUP CHECKLIST

Get a real case moving

  1. Install Switch Console and start or join a server.
  2. Sign in to a supported coding-agent provider. Confirm its free allowance before use.
  3. Use built-in rooms where supported, or connect a messaging app and link your account.
  4. Import switch/proofdesk.template.yaml with this project as the working directory.
  5. Test mentions and handoffs for all three agents.
  6. Prepare a fresh baseline with the command below and paste the generated request into Switch.
python -m scripts.live
