# How to proceed

[Back to index](../../README.md)

The steps below are a suggested execution plan. They are not additional organizer rules.

## First session

1. Read [eligibility and entry rules](../02-rules/README.md).
2. Open the event's **Register now** control yourself and complete registration with your own identity. The public text reader did not expose the working form, so its exact fields remain unverified.
3. Use the community link for teammates and setup help: [WeMakeDevs Discord](https://discord.gg/E2rWw2Yhsm). The invite destination could not be inspected in this research.
4. Choose a primary track from [tracks and judging](../03-tracks-and-judging/README.md).
5. Follow [setup](../05-setup/README.md) until an agent replies in a room.
6. Write one sentence describing the input, responsible agent, human decision, and finished artifact.
7. Select the smallest dataset, repository, or document collection that proves the workflow.

## Suggested daily targets

| Day | Target | Evidence to keep |
| --- | --- | --- |
| November 4 | Setup plus one successful request | Versions, room configuration, first response |
| November 5 | Complete one input-to-output workflow | Generated artifact, logs, handoff transcript |
| November 6 | Improve reliability and reproduction | Fresh-run instructions, failure handling |
| November 7 | Record and submit | Accessible repository, demo, final README |

Leave time to complete the form before the published cutoff. [Official schedule](https://www.wemakedevs.org/hackathons/switch/schedule).

## Suggested workflow contract

Write down who may instruct each agent, what it can access, what counts as success, where results go, and who reviews changes. Make expected failures visible: missing input, unavailable tool, refused action, or an offline agent.

For a two-agent project, test each agent separately before attempting a handoff. Confirm the receiver accepts messages from the sending agent; room membership alone is insufficient. [Agent settings](https://docs.switchagents.ai/switch-rooms/getting-started/agent-settings).

Before adding features, rerun the entire happy path using the exact instructions a judge would receive. Then complete the [submission checklist](../12-submission/README.md).
