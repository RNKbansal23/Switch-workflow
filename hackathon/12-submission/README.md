## Recommended project README contents

This is a suggested structure, not an official form template:

1. Project name, team, primary track, and the problem solved.
2. A concrete example of the input and completed output.
3. Architecture: chat app, room, agents, tool access, and human decisions.
4. Where Switch participates in routing, context, and handoffs.
5. Exact tested versions and prerequisites.
6. Setup steps, sample inputs, and a repeatable demo command/chat request.
7. Room instructions, agent settings, and reusable template/configuration files.
8. Evidence of success and failure behavior.
9. Demo link, limitations, credits, and applicable dependency licenses.
10. What was created during the event and what was reused.

## Suggested demo sequence

- State the problem and show the starting input.
- Show the room and its participants.
- Send the request and show useful work occurring.
- Show a handoff or human review where relevant.
- Open the completed artifact and verify the outcome.
- Briefly show how someone else reproduces it.
