# What is this hackathon?

[Back to index](../../README.md)

Flip the Switch is an online event hosted by WeMakeDevs and DevTools Academy with Switch. It runs November 4–7, 2026; people can participate alone or in teams of at most four. The event schedule includes registration, kickoff, building, submission, judging, and a later winner announcement. [Event schedule](https://www.wemakedevs.org/hackathons/switch/schedule).

## What is Switch?

Switch connects people and AI agents through rooms associated with messaging channels. People request work and make decisions; agents perform tasks and exchange results. A room preserves the conversation and shared materials so another participant can continue the work. Mentioning an agent selects who should act; everyone in the channel can still read the exchange. [Meet Switch](https://docs.switchagents.ai/switch-rooms/using/index).

You bring the agent provider and its model credentials. Switch Console helps register agents, configure rooms, and connect chat platforms. Claude Code, Codex, OpenCode, Cursor, and Antigravity appear in the current provider documentation. A provider runs an agent; the model is configured separately. [Agent providers](https://docs.switchagents.ai/switch-rooms/getting-started/set-up-agent-providers).

## What should your project demonstrate?

**Official challenge:** people and agents complete useful work through Switch; Switch must be essential to the project. Existing agents and libraries are allowed, but the Switch integration and workflow must be made during the event. AI coding tools are permitted. [Challenge and FAQ](https://www.wemakedevs.org/hackathons/switch).

**Practical interpretation:** show a request entering a room, an agent using relevant tools or context, a visible decision or handoff, and an actual output. A reproducible small workflow is a sensible starting point.

Start with [setup](../05-setup/README.md), then [rooms and workflows](../06-rooms-and-workflows/README.md). An ordinary teammate who has already been added to a room can participate through the messaging app without installing Console. [Meet Switch](https://docs.switchagents.ai/switch-rooms/using/index).
