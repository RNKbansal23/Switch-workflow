# Tracks, prizes, and judging

The [event overview](https://www.wemakedevs.org/hackathons/switch) lists:

| Track or award | Published prize |
| --- | --- |
| Business workflow | $2,000 |
| Personal/creative workflow | $2,000 |
| Core contribution | $100 each for 20 PRs |
| Code with Wispr | $500; include an Insights usage scorecard |
| Best blog | AirPods 5; standalone entry allowed |
| #HowISwitch | Five Logitech keyboards |
| Random project draw | Swag for 20 |
| Every project submission | Certificate |

Judging considers Switch's importance, execution/reproducibility, creativity/impact, and presentation. WeMakeDevs shortlists; the joint panel selects finalists' winners. [Judging section](https://www.wemakedevs.org/hackathons/switch#judging).

## Details to confirm

The overview advertises $10,000, but its listed cash awards total $6,500. Contribution prizes mention 20 PRs, while judging mentions 10. The extracted judging percentages are all zero; usable weights are unverified. Ask the organizers before relying on these details. [Published overview](https://www.wemakedevs.org/hackathons/switch).

## Practical track choice

Choose one primary outcome that you can complete and explain. A business entry could produce a tested bug fix; a creative entry could produce an editorial draft and review trail. A contribution entry requires a change to Switch itself: follow [the contribution guide](../10-core-contributions/README.md).

For the voice side track, the event's [Wispr offer](https://wisprflow.ai/?promo_code=WEMAKEDEVS&utm_campaign=wemakedevs&utm_medium=partner&utm_source=wemakedevs) is linked here for reference; verify account eligibility before using it. No account or subscription was created during this research.
